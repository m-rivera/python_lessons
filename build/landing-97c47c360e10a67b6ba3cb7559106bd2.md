# Connecting to a remote service
 
We will now connect to a remote service using their API to get information back (we can also send information, but won't do so in these examples)
 
## Connecting to RSpace
 
RSpace is the provider of UCL's electronic research notebook and has a full API that we can interact with. In this example we will connect to RSpace and get a list of items in it.
 
First we need to set up authentication so we can access the ERN, to do this we will follow the instructions given by [RSpace](https://documentation.researchspace.com/l/en/article/v0dxtfvj7u-rspace-api-introduction) to generate an API key. As you will log into RSpace usin OAuth you may need to set up a 'Verification Password' to generate an API key
 
Note:
An API key is the equivalent of your password, do not share with anyone. For these examples we will put the key into our scripts. But for proper use it should be secured separately
 
 
We can test the API using [RSpace's API documentation](https://community.researchspace.com/public/apiDocs)
 
Click on the Authorize button. Enter your API key and click log in. Then scroll down to find Get userDetails/whoami.
 
Expand the box click 'Try it out' then 'Execute', this should return a Code 200 response giving your id and username for Rspace. If it returns 401 then the API key is not set up correctly
 
Now we can send the same request in Python.
 
Copy the following code and put your API key in the appropriate place
 
```python
import requests
 
Rspace_url = "https://ern.ucl.ac.uk/api/v1/"
Rspace_key = "YOU KEY HERE"
 
Rspace_api = "userDetails/whoami"
 
Rspace_api_url = Rspace_url + Rspace_api
 
headers = {"accept": "application/json", "apiKey": Rspace_key}
 
response = requests.get(Rspace_api_url, headers=headers)
 
# Raise an exception if the request failed
response.raise_for_status()
 
# Parse JSON response
data = response.json()
print(data)
```
 
The response is in what is called JSON (Jave Script Object Notation) which is converted into a Python dictionary (called data) that we can use as required.
 
For example, replace the print(data) line with:
 
```python
print(f" Hello {data['firstName']} your Rspace id is {data['id']}")
```
 
Finally, we should be aware that the requests could fail for a variety of reasons (such as not being authorised or a lack of connectivity). Therefore we should catch any problems.

The Rspace API documentation tells us what responses to expect, 200 is all is good. Anything above 400 is bad.

## Connecting to ChemInventory
 
ChemInventory is being used as the department Inventory, we can also connect to that. Log into ChemInventory and use the [API documentation](https://www.cheminventory.net/support/api) to acquire an API Key (referred to as authenication token by ChemInventory, same thing)
 
Now we can run calls to get (or add) information to our ChemInventory
 
```python
import requests
 
authtoken = "enter your API key here"
 
Cheminv_url = "https://app.cheminventory.net/api/"  # The root api
Cheminv_api = "general/getdetails"
Cheminv_api_url = Cheminv_url + "general/getdetails"
 
myRequest = requests.post(
    Cheminv_api_url,
    timeout=10,
    json={"authtoken": authtoken},
)
status_code = myRequest.status_code
 
if status_code == 200:
    data = myRequest.json()
    print(data)
elif status_code >= 400:
    print(f"Error in connection, code {status_code}")
```
 
As you can see the JSON output in this case is hard to read. We can use a built in library to make this more readable.
Add ```import json``` to the top of the script. Then replace print(data) with
```python
    json_formatted_str = json.dumps(data, indent=2)
    print(json_formatted_str)
```
This is a very, very, very, nested output, which can be a bit tricky to manipulate. Add this print statement to get some user information
 
```python
    print(f" Hello {data['data']['user']['firstname']} your ChemInventory id is {data['data']['user']['id']}")
```

## Getting Chemical information
 
Finally lets connect to a service that can provide information on a given chemical [CAS Common Chemistry](https://commonchemistry.cas.org/)
 
Go to the website and register for an API key.
 
If we know the CAS number of a chemical then we can look up its details. Try the following code
 
```python
import requests
import json
 
cas_chem_url = "https://commonchemistry.cas.org/api/"
cas_api = "Your Key Here"
 
cas_chem_api = "detail"  # the API endpoint we will call
 
cas_chem_api_url = cas_chem_url + cas_chem_api  # full API path for request
 
 
headers = {
    "X-API-KEY": cas_api,
}
 
params = {
    "cas_rn": "1303-28-2",
}
 
response = requests.get(cas_chem_api_url, params=params, headers=headers)
 
if response.status_code == 200:
    data = response.json()
    json_formatted_str = json.dumps(data, indent=2)
    print(json_formatted_str)
```
